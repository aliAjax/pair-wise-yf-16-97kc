# 双板配对验收台 · 滑雪板调校维护

双板常分给不同技师打磨，前台收回两块板时需要判断能否作为一副交付。本页面把工单登记与双板配对验收集中到一个工位：

- 每张工单登记**客户、板型（含品牌型号）**，以及左右板各自的**侧刃角、底刃角、蜡型、底板损伤**（位置 / 描述 / 长度 / 已修补）。
- 配对规则：两侧**侧刃角差 > 0.50°** 或**底刃角差 > 0.25°** 即判为不能配对；判定只读取数值，**原始测量值原样保留**，并在卡片与验收记录中指明差值大小、限值以及差在左板还是右板。
- 配对**通过后**，任一侧侧刃 / 底刃角被改动，或底板损伤有增删，这副板自动回到**待复核**，需重新执行配对验收；待复核 / 不通过状态不会因为编辑而自动洗白。
- **客户历史保留每次验收差值**（通过与不通过都留痕），可按客户 / 工单号检索。
- 所有数据只存浏览器（localStorage，键 `ski-pairing-orders-v1`），可用「清空浏览器数据」重置；首次打开内置演示工单。
